# Kundali Engine

A professional Vedic Astrology Engine written in Python using Swiss Ephemeris.

## Features

- High precision Swiss Ephemeris calculations
- Lahiri Sidereal Zodiac
- Planetary Positions
- Nakshatra Calculation
- Pada Calculation
- Ascendant (Lagna)
- House Cusps
- Timezone Support
- UTC Conversion

## Requirements

Python 3.9+

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
